Overview

low-code-engine is an Angular library built from the Metadata project. It exposes the render engine, runtime components, registry, state/query/action services, and provideLowCodeEngine().

Important rule

Install the library in consumer apps from a packed .tgz file or registry package, not from dist/low-code-engine directly. Direct file installs can become symlinks and cause duplicate Angular runtimes.

Use in Another Product

Install the required peer dependency and the packed engine package.

npm install angular-oauth2-oidc@^20.0.2
npm install D:\Projects\TTD\package-cache\low-code-engine-0.0.1.tgz

Provider Setup

Register Angular Router, OAuth, the engine providers, and built-in components.

import { APP_INITIALIZER, ApplicationConfig, provideBrowserGlobalErrorListeners } from '@angular/core';
import { provideRouter } from '@angular/router';
import { provideOAuthClient } from 'angular-oauth2-oidc';
import { BUILT_IN_COMPONENTS, ComponentRegistry, provideLowCodeEngine } from 'low-code-engine';

function registerBuiltIns(registry: ComponentRegistry) {
  return () => {
    registry.registerPlugin({
      id: 'built-in',
      name: 'Built-in components',
      version: '0.0.1',
      components: BUILT_IN_COMPONENTS.map(component => ({
        ...component,
        schema: (component as { schema?: [] }).schema ?? []
      }))
    });
  };
}

export const appConfig: ApplicationConfig = {
  providers: [
    provideBrowserGlobalErrorListeners(),
    provideRouter([]),
    provideOAuthClient(),
    provideLowCodeEngine({
      apiUrl: '',
      authServerUrl: '',
      clientId: '',
      graphqlUrl: ''
    }),
    {
      provide: APP_INITIALIZER,
      useFactory: registerBuiltIns,
      deps: [ComponentRegistry],
      multi: true
    }
  ]
};

Mount Schema

Inject RendererService and mount metadata into a normal DOM element.

import { AfterViewInit, Component, ElementRef, ViewChild, inject } from '@angular/core';
import { RendererService } from 'low-code-engine';

@Component({
  selector: 'app-root',
  template: '<div #renderHost></div>'
})
export class App implements AfterViewInit {
  @ViewChild('renderHost', { static: true }) renderHost!: ElementRef<HTMLElement>;

  private readonly renderer = inject(RendererService);
  private destroyRender?: () => void;

  async ngAfterViewInit() {
    this.destroyRender = await this.renderer.mount({
      id: 'root',
      type: 'row',
      children: [
        {
          id: 'title',
          type: 'text',
          props: { text: 'Rendered by low-code-engine' }
        }
      ]
    }, this.renderHost.nativeElement);
  }

  ngOnDestroy() {
    this.destroyRender?.();
  }
}

Rebuild After Library Updates

  1. 1. Build the library from Metadata
    cd D:\Projects\TTD\Metadata
npm run build:engine
  2. 2. Pack the built library into a tarball
    New-Item -ItemType Directory -Force -Path D:\Projects\TTD\package-cache
npm pack D:\Projects\TTD\Metadata\dist\low-code-engine --pack-destination D:\Projects\TTD\package-cache
  3. 3. Install the new tarball in the consuming product
    cd D:\Projects\TTD\metadata-engine-consumer
npm install D:\Projects\TTD\package-cache\low-code-engine-0.0.1.tgz
  4. 4. Rebuild and serve the consumer
    npm run build -- --configuration development
npx http-server dist\metadata-engine-consumer\browser -p 4300 -a 127.0.0.1 -c-1

Troubleshooting

NG0203 injection error

Check for duplicate Angular runtimes. Do not install the library from dist/low-code-engine as a direct file link. Use npm pack and install the generated .tgz.

No provider for OAuthService

Install angular-oauth2-oidc and add provideOAuthClient() to the consumer app providers.

Old error still appears after rebuild

Restart the server and open a cache-busted URL such as http://127.0.0.1:4300/?v=new-build.
