Tài liệu API: Flow Phiếu Tiền Sử Dị Ứng

Hướng dẫn chi tiết các bước gọi API từ Frontend để khởi tạo, cập nhật, tải lại và ký số phiếu khai thác tiền sử dị ứng cho bệnh nhân.

Luồng thực thi (Flow)

  1. 1

    User chọn tạo phiếu

    Gọi API khởi tạo. Backend tự động map DocumentModel, tạo DocumentData và tạo tbl_PhieuKhaiThacTienSuDiUng.

  2. 2

    Nhận định danh (IDs)

    Frontend nhận về documentDataId và phieuId để sử dụng cho các thao tác tiếp theo.

  3. 3

    Nhập & Lưu dữ liệu

    User điền form. Frontend gửi request PUT để lưu nháp hoặc hoàn tất phiếu.

  4. 4

    Ký số (Tuỳ chọn)

    Thực hiện ký điện tử/chữ ký số để chốt hồ sơ, không cho phép chỉnh sửa nữa.

1. Khởi tạo Phiếu mới

POST
POST /api/emr/visits/{visitId}/forms/allergy-history

API này được gọi khi người dùng bấm nút "Thêm phiếu dị ứng". Nó sẽ trả về các ID cần thiết để thao tác.

Response (200 OK)

{
  "documentDataId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "phieuId": "12345678-1234-1234-1234-123456789012",
  "documentType": "Phiếu khai thác tiền sử dị ứng",
  "status": "Draft"
}

2. Load dữ liệu Phiếu (Mở lại)

GET
GET /api/emr/documents/{documentDataId}/forms/allergy-history/{phieuId}

Gọi khi người dùng đóng form và mở lại. Dùng để bind dữ liệu cũ lên giao diện.

Response (200 OK)

{
  "id": "12345678-1234-1234-1234-123456789012",
  "documentDataId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "thuocDiNguyen": "Paracetamol",
  "thuocDiNguyenCoKhong": true,
  "thuocDiNguyenSoLan": 1,
  "thuocDiNguyenBieuHien": "Nổi mề đay",
  "thucPham": null,
  "thucPhamCoKhong": false,
  ...
}

3. Lưu / Cập nhật Phiếu

PUT
PUT /api/emr/documents/{documentDataId}/forms/allergy-history/{phieuId}

Gửi toàn bộ các field trong form khi người dùng bấm "Lưu".

Request Body (JSON)

{
  "thuocDiNguyen": "Paracetamol",
  "thuocDiNguyenCoKhong": true,
  "thuocDiNguyenSoLan": 2,
  "thuocDiNguyenBieuHien": "Khó thở, nổi mẩn đỏ",
  "conTrung": "Ong đốt",
  "conTrungCoKhong": true,
  ...
}

Response (200 OK)

{
  "message": "Form saved successfully."
}

4. Ký số hoàn tất bệnh án

POST
POST /api/signature/documents/{documentDataId}/sign

Sử dụng để chốt hồ sơ. Sau khi ký, API Cập nhật (PUT) sẽ tự động bị khoá (Trả về 400 Bad Request).

Request Body (JSON)

{
  "signatureType": "ELECTRONIC_SIGNATURE",
  "signatureId": "ID_CHU_KY_DIEN_TU_CUA_BAC_SI",
  "reason": "Xác nhận phiếu tiền sử dị ứng"
}
